## Descripción del proyecto
Aplicación de consola desarrollada en Python para gestionar una agenda semanal de cinco películas. El proyecto está dividido de forma modular en `modulo_peliculas.py` (lógica, cálculos y validaciones de reglas de horario e invitación) y `consola_peliculas.py` (menú interactivo por consola).
